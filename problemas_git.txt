No veo todas las ramas en origin
    Solución:
        git remote set-branches origin '*'
        git fetch --all --prune
        git branch -r

Si quieres que main y luisa queden iguales, primero integras luisa en main, y luego traes main de vuelta a luisa.

Pasos:

# 1) Meter luisa en main
git checkout main
git pull
git merge luisa
git push

# 2) Poner luisa igual que main (con merge, sin reset)
git checkout luisa
git fetch origin
git merge origin/main
git push
